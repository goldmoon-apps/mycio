## 2. 앱이 읽는 정보

모든 기록은 **사용자의 휴대폰 안**에만 저장됩니다. 만든 곳의 서버는 없으며, 만든 곳은 사용자의 기록을 볼 수 없습니다.

## 4. 밖으로 나가는 경우 (사용자가 직접 켠 경우만)
- **AI 도우미**: 질문할 때 답에 필요한 기록 요약(금액 · 가게 · 분류 · 날짜)을 사용자가 연결한 AI 서비스(Google Gemini, OpenAI, Anthropic)로 보냅니다. 각 회사의 개인정보 처리방침이 적용됩니다. AI 키는 휴대폰 안에만 저장합니다.
- **내 구글 시트로 보내기**: 사용자 본인 구글 계정의 시트에 기록을 한 줄씩 보냅니다(앱이 만든 파일에만 접근하는 권한을 씁니다).
- **사용자가 주소를 넣은 웹 앱으로 보내기**(선택).
- **백업**: 사용자가 고른 위치(내 파일 · 구글 드라이브 등)에 백업 파일을 저장합니다. AI 키는 백업에 넣지 않습니다.
- **음성 호출어 모델**: 처음 켤 때 공개된 모델 파일을 내려받기만 합니다(사용자 정보는 보내지 않습니다).
